## 🔍 How to Search and View Buses

### Step 1: Open Search
- Tap on "Search" tab in bottom navigation
- See "Plan your trip" screen

### Step 2: Select Route
**From:** Choose any origin city
- Bangalore Central Station
- Visakhapatnam RTC Complex
- Or any intermediate stop

**To:** Choose any destination city
- Mysore, Pune, Hyderabad, Goa, Chennai
- Or any intermediate stop

### Step 3: View Results
Search returns all matching routes with:
- ✅ Route details (number, name, distance)
- ✅ Live bus information (status, speed, occupancy)
- ✅ ETA to destination
- ✅ Current passenger count
- ✅ Fare information

### Step 4: View on Map
- Tap on search result to see route on map
- Map shows:
  - 🟢 Origin stop
  - 🔴 Destination stop
  - 🚌 Live bus position
  - 📍 All intermediate stops
  - Bus movement in real-time

- Each bus updates position every 2-3 seconds
